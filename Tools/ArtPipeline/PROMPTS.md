# Super Ottie art prompts

Generate each image in ChatGPT, download it, and save it into `~/Develop/ottie-art/raw/` with the exact file name shown.
For the three prompts marked **attach reference**, attach `~/Develop/ottie-art/ottie_reference.jpg` (the Ottie photo) to the message.
White backgrounds are expected; I remove them afterwards.

## 1. Ottie sprite sheet (8 poses)  ->  `player_sheet.png`  (attach reference)

```
Create this image: Image: a game sprite sheet of the hero 'Ottie', a chubby baby otter matching the attached reference image (warm brown fur, cream belly, cream muzzle and cheeks, big ROUND BLACK GLASSES, big friendly dark eyes, two small buck teeth, small round ears, thick tapered tail). Chibi proportions: big head (about 45% of height), round chubby belly, short stubby legs and arms. Same character, same colors and same size in every pose.
Style: polished 2D side-scrolling platformer game art, cute chunky cartoon in the spirit of a modern Nintendo 2D Mario game, bold clean dark-brown outlines, soft cel shading with 2-3 tones, bright saturated colors. No text, no letters, no numbers, no watermark, no signature.
Layout: landscape 1536x1024 image, 8 poses in a 4 columns x 2 rows grid, every pose the SAME scale, generous white gap between poses so they never touch or overlap. Poses 1-6 are strict SIDE VIEW facing RIGHT:
Row 1: (1) idle standing, (2) running frame: left leg forward, arms swinging, (3) running frame: legs passing under body, (4) running frame: right leg forward, arms swinging.
Row 2: (5) jumping up: one fist raised, legs tucked, (6) falling: arms out, legs dangling, (7) hurt: dizzy spiral eyes, facing the viewer, (8) victory: both arms up cheering, facing the viewer.
Background: pure flat white (#FFFFFF) everywhere around the objects, no ground, no cast shadows, no floor line, no frames, no borders, no grid lines.
```
